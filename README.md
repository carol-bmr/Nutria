# NUTRIA

**Il tuo piano. Pensato per te.**

Planner alimentare personale: genera automaticamente un piano settimanale su misura, con
ricettario, calendario e lista della spesa.

## 🔗 Apri l'app

**[https://carol-bmr.github.io/Nutria/](https://carol-bmr.github.io/Nutria/)**

Funziona da telefono, tablet o computer — nessuna installazione richiesta. Su telefono, dal
menu del browser puoi scegliere "Aggiungi a schermata Home" per usarla come un'app vera.

## Cosa fa

- 🍽️ **Piano settimanale automatico**, calcolato sul tuo fabbisogno energetico
- 📖 **200 ricette** filtrabili per momento della giornata, tempo di preparazione, attrezzatura
  disponibile in cucina e se il pasto va portato fuori casa
- 📅 **Calendario** per consultare e modificare il piano giorno per giorno
- 🛒 **Lista della spesa** generata automaticamente dagli ingredienti della settimana
- 👤 **Account facoltativo** per salvare i dati anche cambiando dispositivo
